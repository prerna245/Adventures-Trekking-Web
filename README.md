# 🏔️ Adventures Trekking Web

**Adventures Trekking Web** is a web-based trekking management application designed to make trekking activities easier to manage for **admins, staff, and trekkers/users**.

The platform allows users to explore and register for trekking adventures, while admins and staff can manage treks and user-related activities.

## ✨ Features

### 👨‍💼 Admin

* Manage trekking adventures
* Add, update, and delete trek details
* Manage registered users
* Manage staff members
* Approve or manage trekking registrations
* Monitor overall trekking activities

### 🧑‍💼 Staff

* View assigned trekking activities
* Manage trek-related information
* Handle trek participants
* Update trekking activity details

### 🧑 User / Trekker

* Register and log in to the website
* Browse available trekking adventures
* View trek details
* Register for trekking activities
* View personal trekking information

| Role             | Main Responsibilities                                |
| ---------------- | ---------------------------------------------------- |
| **Admin**        | Manage treks, users, staff, and overall activities   |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/prerna245/Adventures-Trekking-Web.git
```

### 2. Go to the project directory

```bash
cd Adventures-Trekking-Web
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Then open the local URL shown in the terminal, usually:

```text
http://127.0.0.1:5000/
```

## 📌 Project Purpose

The main goal of this project is to provide a simple platform for managing trekking adventures while giving different users appropriate access based on their roles.

It also demonstrates the use of **Flask, database management, authentication, CRUD operations, role-based access, and web application development**.
